ZORYNTH

A custom Windows launcher for a Minecraft Java Edition fantasy MMORPG project.

About the Project

ZORYNTH Launcher is an independently developed desktop application built with C# and WPF for Windows. It is designed to provide a dedicated experience for a fantasy-themed Minecraft project, including game preparation, installation status, and account management.

Features

Game Preparation

Prepares and verifies Minecraft Java Edition 1.21.1 game files and required resources.

NeoForge Support

Supports the NeoForge 21.1.265 modding environment.

Fantasy Interface

Custom launcher interface themed around the ZORYNTH fantasy world.

Microsoft Account Authentication

ZORYNTH is being developed to authenticate players through Microsoft's official browser-based sign-in process. The launcher does not request or collect Microsoft account passwords.

Its authentication implementation checks Minecraft Java Edition ownership and retrieves the player's profile before permitting a game launch. Live authentication is pending application review and approval.

Why Minecraft Services Access Is Needed

ZORYNTH requests application approval to support legitimate Microsoft account sign-in, Minecraft Java Edition entitlement verification, and access to the authenticated player's Minecraft profile. The project does not intend to bypass authentication or game ownership requirements.

Project Status

ZORYNTH is under active development. Game file preparation and automated tests have been implemented; the first authenticated Minecraft launch has not yet been completed. No public download is currently offered on this page.
